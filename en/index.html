Player Ascend Beta

Web app for players of ARAM Mayhem, a League of Legends mode

Live and being tested with real users. New accounts are approved manually.

Open the app (opens in a new tab)Private code
The problem
ARAM Mayhem has no official ranked queue. People who play this mode have no way to tell whether they are improving from one match to the next.
What I built
A program on the player’s computer reads matches while League of Legends is open and sends the data to the site, which scores every match and shows progress over time.

Highlights

  • Performance Score: a 0 to 100 score for every match that goes beyond KDA.
  • Ascend Points and a custom 10-tier ladder, from Cardboard to Legendary.
  • Friend comparison and a global leaderboard only for people who opt in. By default, only you see your data.
  • Accounts are approved by hand and deactivated after 20 days without use, to fit the free plan.

Technologies

  • React
  • Vite
  • Supabase
  • Vercel
  • Data Dragon (Riot)

Owldit Beta

App that alerts you when earnings reports come out for your Brazilian stocks

Live and being tested with real users. New accounts are approved manually.

Open the app (opens in a new tab)Private code
The problem
Keeping up with quarterly earnings and material facts for every company in a portfolio takes time. And people outside finance often don’t know what to look at.
What I built
An app that follows the stocks you choose and sends a simple alert to your phone or computer when an earnings report or material fact is released. It only alerts: it never tells you to buy or sell.

Highlights

  • Installable as an app (PWA), with notifications on phone and computer.
  • Available in Portuguese and English, with light, dark or automatic theme.

Reldor In development

Command-line tool with an AI plugin for developers working on the Salesforce platform

The repository holds the first version, built for a presentation. A new version is being built.

View the code (opens in a new tab)
The problem
AI writes code for the Salesforce platform fast, but it can’t see the whole org: the flow that runs before the trigger, the rule that breaks another team’s test. Developers only find out about the impact later, when something breaks.
What I built
A tool that reads the project’s metadata and works out those facts with scripts, plus a plugin that teaches the AI to use it. The idea is to show the impact of each change before the commit.

Highlights

  • The script finds the facts, not the AI, so the answer is always the same.
  • Built to work with Kiro and Claude Code.
  • Never runs anything in Git or the org: you decide and run the commands.

Technologies

  • Node.js
  • MCP
  • GitHub Actions
  • Salesforce CLI
